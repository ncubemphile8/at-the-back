# At the Back — The Food

Responsive restaurant website for At the Back, a braai and traditional-food spot in Matshemhlophe, Bulawayo.

## Deploy
Static HTML/CSS/JS site. Import this repository into Vercel with no build command and project root as the output directory.

## Launch notes
- `logo.svg` is a temporary vector brand mark. Replace it with the supplied official logo asset before launch.
- Video and food photography are remote demo assets.
- Confirm the second contact number and menu wording/prices before launch.
